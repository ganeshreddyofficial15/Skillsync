# SkillSync 🚀

SkillSync is a full-stack web application designed to solve a major student pain point: finding reliable, multidisciplinary teammates for hackathons, coding challenges, and semester lab projects without messy group chat spam.

## Features
- **Project Postings:** Publish team requirements for events like the Google Solution Challenge or hackathons.
- **Skill Matching:** Tag required technologies (React, Python, Node.js, Java) to find the right talent.
- **Developer Profiles:** Showcase your skills and bio.

## Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (Responsive UI)
- **Backend:** Node.js, Express.js
- **Database:** SQLite3
